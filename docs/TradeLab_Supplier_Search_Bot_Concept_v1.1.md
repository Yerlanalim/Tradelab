**Версия:** 1.1  
**Дата:** 21.01.2026  
**Статус:** Концепция для разработки

## 1. Суть продукта

**Supplier Search Bot** — диалоговый AI-бот для поиска и предварительного скорринга китайских поставщиков. Заменяет устаревший подход с legacy scrapers на нативный LLM с web search.

### 1.1. Ключевое ценностное предложение

> **"Скажи боту, что ищешь — получи топ-10 проверенных поставщиков за 3 минуты"**

- Вместо 50 открытых вкладок — структурированный отчёт
- Вместо недели поиска — диалог на 3 минуты
- Вместо гадания "кто надёжный" — скорринг с светофорами

### 1.2. Позиционирование

| Способ поиска | Время | Результат | Стоимость |
|---------------|-------|-----------|-----------|
| Самостоятельно на Alibaba | 3-5 дней | Хаос из 50+ вкладок | Бесплатно |
| Sourcing агент | 1-2 недели | 5-10 вариантов | $500-2000 |
| **TradeLab бот** | **3 минуты** | **Топ-10 + анализ + PDF** | **500 TC (~$5 / 2,500 ₸)** |

### 1.3. Почему диалоговый формат

- **Низкий барьер входа:** не нужно заполнять формы, просто пишешь
- **Гибкость:** бот сам уточняет детали, адаптируется под запрос
- **Perceived value:** ощущение персонального сервиса
- **Естественный апсейл:** "Хочешь проверить этого поставщика?" — органично в диалоге
- **Retention:** пользователь возвращается к "своему боту"

## 2. Архитектурные изменения

### 2.1. Что удаляем

| Компонент | Действие | Причина |
|-----------|----------|---------|
| Legacy scraper акторы (Alibaba) | Удалить | Дорого, ненадёжно, средние результаты |
| Legacy scraper акторы (Made-in-China) | Удалить | Дорого, ненадёжно, средние результаты |
| Legacy scrapers subscription | Отменить | Больше не нужна |
| Страница "Поиск поставщиков" (старая) | Удалить | Заменяется ботом |
| Edge Functions для legacy scrapers | Удалить | Заменяются на LLM web search |

### 2.2. Что сохраняем и переиспользуем

| Компонент | Использование |
|-----------|---------------|
| PDF-генерация (React-PDF) | Экспорт отчёта бота в PDF |
| Excel-генерация | Экспорт отчёта в Excel |
| Supabase Auth | Авторизация пользователей |
| Supabase Database | Хранение истории диалогов, отчётов, Trade Credits |
| OpenAI API | Ядро бота + web search |
| AI-чат компоненты | Адаптируем под бота-поисковика |

### 2.3. Новая архитектура

```
Пользователь
    ↓
Диалоговый интерфейс (React)
    ↓
Edge Function (обработка сообщений)
    ↓
OpenAI GPT + Web Search Tool
    ↓
Структурированный JSON-ответ
    ↓
Рендеринг отчёта в чате
    ↓
Экспорт PDF/Excel (по запросу)
```

## 4. Внутренняя логика бота

### 4.1. Этап 1: Сбор данных (Web Search)

LLM с web_search выполняет поиск по запросу пользователя:

**Промпт для поиска:**
```
Найди поставщиков [товар] на Alibaba.com и Made-in-China.com.

Критерии:
- Грузоподъёмность/характеристики: [параметры]
- Ценовой диапазон: [мин-макс]
- Состояние: [новое/б/у]

Для каждого поставщика собери:
- Название компании
- Название модели
- Цена (диапазон)
- Тип компании (производитель/трейдер)
- Статус на площадке (Gold Supplier, Audited, годы)
- Ключевые характеристики товара
- Ссылка на карточку
```

### 4.2. Этап 2: Дедупликация

Бот удаляет дубликаты по:
- Названию компании (с нормализацией: "HELI" = "Anhui Heli Co." = "HELI Co., Ltd.")
- Одинаковые модели от разных продавцов → оставляет с лучшим статусом

### 4.3. Этап 3: Скорринг

**Факторы скорринга:**

| Фактор | Вес | Описание |
|--------|-----|----------|
| Тип компании | 25% | Производитель > Торговая компания |
| Стаж на площадке | 20% | Больше лет = надёжнее |
| Верификация | 20% | Audited, Gold Supplier, Trade Assurance |
| Соответствие цене | 15% | Попадание в заявленный диапазон |
| Полнота информации | 10% | Есть характеристики, фото, контакты |
| Подозрительные признаки | 10% | Слишком низкая цена, новый аккаунт |

**Результат скорринга:**
- 🟢 70-100 баллов — Низкий риск
- 🟡 40-69 баллов — Средний риск
- 🔴 0-39 баллов — Высокий риск

### 4.4. Этап 4: Enrichment (для топ-10)

Для отобранных 10 поставщиков бот дополнительно ищет:
- Подробности о компании (город, размер, история)
- Отзывы и упоминания
- Данные об экспорте в СНГ (если доступны)

### 4.5. Этап 5: Формирование отчёта

Бот генерирует структурированный JSON, который рендерится в интерфейсе:

```
{
  "query_summary": {...},
  "price_corridor": {...},
  "suppliers": [
    {
      "rank": 1,
      "risk_level": "green",
      "company": {...},
      "product": {...},
      "risk_factors": [...],
      "recommendations": [...]
    },
    ...
  ]
}
```

## 5. Светофорная система (Risk Matrix)

### 5.1. Зелёный 🟢 — Низкий риск

**Критерии:**
- Производитель (не трейдер)
- 5+ лет на площадке
- Audited Supplier или Gold Supplier
- Trade Assurance
- Цена в рыночном коридоре
- Есть данные об экспорте

**Сообщение пользователю:**
> ✓ Похоже на надёжного поставщика
> ✓ Рекомендуется стандартная проверка перед заказом

### 5.2. Жёлтый 🟡 — Средний риск

**Критерии:**
- Один или несколько факторов отсутствуют
- Торговая компания с хорошей репутацией
- 2-5 лет на площадке
- Нет данных об экспорте в СНГ

**Сообщение пользователю:**
> ⚠️ Требуется дополнительная проверка
> 💡 Рекомендуем: [конкретные действия]

### 5.3. Красный 🔴 — Высокий риск

**Критерии:**
- Цена значительно ниже рынка (>30%)
- Менее 2 лет на площадке
- Нет верификации
- Торговая компания без Trade Assurance
- Противоречивая информация

**Сообщение пользователю:**
> 🚨 Высокий риск — тщательная проверка обязательна
> 🚨 [Конкретные красные флаги]
> 💡 Рекомендуем: проверить юридический статус, запросить референсы, не вносить предоплату без гарантий

## 6. Интеграция с другими продуктами TradeLab

### 6.1. Апсейл в отчёте

Каждая карточка поставщика содержит кнопки:

| Кнопка | Продукт | Стоимость |
|--------|---------|-----------|
| "Проверить компанию" | Продукт 1 (Справка о компании) | 2,000 TC |
| "Экспортный профиль" | Продукт 2 (Экспортный профиль) | 2,000 TC |
| "Проверить компанию + Экспорт" | Бандл 1+2 | 3,500 TC |

### 6.2. Cross-sell после отчёта

**Бот предлагает:**
- Определить HS-код (бесплатно)
- Рассчитать landed cost (бесплатно)
- Сформировать RFQ (100 TC)
- Анализ рынка поставок в КЗ (Продукт 4, 5,000 TC)

### 6.3. Интеграция с Tendata (будущее)

При наличии доступа к Tendata API, бот может добавлять в отчёт:
- Факт экспорта компании (Да/Нет/Неизвестно)
- Экспорт в СНГ (Да/Нет)
- Примерные объёмы

Это превращает отчёт из "списка с Alibaba" в **верифицированный shortlist**.
