**Версия:** 2.1  
**Дата:** 15.01.2026  
**Статус:** Единый концептуальный документ

## 1. Суть проекта

**TradeLab** — self-service платформа инструментов для импортёров из Казахстана и ЕАЭС, которые работают с китайскими поставщиками.

### 1.1. Ключевое ценностное предложение

> **Мы продаём время, уверенность и структурированные решения.**
> 
> - Юридическая справка о компании — за минуты вместо дней
> - Экспортный профиль с оценкой релевантности — вместо гадания
> - Подбор поставщиков с ценовым бенчмарком — вместо 50 открытых вкладок
> - Анализ реальных поставок в Казахстан — вместо слепого поиска

### 1.2. Чем TradeLab НЕ является

- ❌ Не маркетплейс — нет участия в сделках
- ❌ Не sourcing-агент — не ведём переговоры за клиента
- ❌ Не гарант — нет escrow, нет комиссий с товара
- ❌ Не логист — только ориентиры по стоимости

### 1.3. Бизнес-модель

**Оплата за конкретный результат:**
- Отчёты и справки по фиксированной цене
- Бесплатные инструменты как лид-магниты (после регистрации)
- Контентные разделы для удержания и экспертизы

## 2. Целевая аудитория

### 2.1. Портрет клиента

| Параметр | Описание |
|----------|----------|
| **Роль** | Собственник или закупщик малого/среднего бизнеса |
| **География** | Казахстан (основной), Узбекистан, Кыргызстан, Россия |
| **Оборот компании** | $100K–$5M/год |
| **Опыт импорта** | От новичка до опытного (3-20 контейнеров/год) |
| **Платёжеспособность** | Платит с личной или корпоративной карты |

### 2.2. Jobs to be Done

1. **Проверить контрагента юридически** — "Компания существует? Какой статус? Есть ли судебные дела?"
2. **Оценить экспортную активность** — "Они реально экспортируют? Куда? Какие объёмы?"
3. **Найти релевантных поставщиков** — "Кто производит этот товар? По каким ценам?"
4. **Понять рынок поставок** — "Кто реально возит этот товар в Казахстан?"

## 3. Продуктовая линейка

### 3.1. Обзор продуктов

| # | Продукт | Цена | Источник | Маржа |
|---|---------|------|----------|-------|
| 1 | Справка о компании + Интерпретация | $20 | QCC | 75–85% |
| 2 | Экспортный профиль + Релевантность к сделке | $20 | Tendata | 75–85% |

### 3.2. Продукт 1: Справка о компании + Интерпретация ($20)

**Суть:** Официальная справка о китайской компании на основе данных госреестра КНР.

**Входные данные:**
- **Unified Social Credit Code (USCC)** — 18 символов
- Пользователь получает USCC от поставщика (инструкция на сайте)

**Что включено (данные):**

| Раздел | Данные |
|--------|--------|
| Регистрация | Название (中文/EN), дата, статус (Active/Inactive) |
| Тип компании | Производитель / Торговая / Смешанная |
| Капитализация | Уставный капитал, изменения |
| Руководство | Законный представитель, ключевые лица |
| Акционеры | Учредители, доли |
| Business scope | На китайском + перевод |
| Адрес | Юридический адрес |
| Контакты | Телефон/email (если доступны) |
| Юр. история | Судебные дела, чёрные списки, нарушения |

**Что включено (интерпретация):**
- 🟢 Green flags — признаки устойчивости
- 🟡 Yellow flags — зоны для уточнения
- 🔴 Red flags — сильные риски
- Рекомендованные вопросы поставщику (5-7 вопросов)

**Формат:** PDF, 2-3 страницы, брендированный

**Источник:** QCC (Qichacha) Singapore API

---

### 3.3. Продукт 2: Экспортный профиль + Релевантность к сделке ($20)

**Суть:** Аналитический отчёт об экспортной активности компании за последние 12 месяцев.

**Входные данные:**
- USCC (предпочтительно)
- Или название компании (EN/中文)

**Что включено (данные):**

| Раздел | Данные |
|--------|--------|
| Факт экспорта | Подтверждение активности |
| Период | Первая/последняя отгрузка |
| Объёмы | Общий объём USD (оценка) |
| География | Топ-10 стран |
| Экспорт в СНГ/ЕАЭС | KZ/RU/UZ/KG — отдельным блоком |
| HS-коды | HS-направления экспорта |
| Динамика | График по месяцам, тренд |
| Частота | Среднее отгрузок/месяц |

**Блок "Релевантность к сделке":**
- **HS match** — совпадает ли экспорт с вашим товаром
- **Масштаб** — сопоставимы ли объёмы с вашей потребностью
- **Стабильность** — регулярность поставок
- **Региональная пригодность** — опыт поставок в СНГ

**Формат:** PDF, 3-4 страницы

**Источник:** Tendata API

---

### 3.4. Продукт 3: Поиск поставщиков + Price/MOQ Bench ($10)

**Суть:** Мультиплатформенный поиск поставщиков с фокусом на релевантность, не на количество.

**Процесс:**
1. AI-диалог: товар + атрибуты + HS + бюджет
2. Формирование запросов EN/ZH
3. Поиск (Alibaba + Made-in-China)
4. Дедупликация + фильтрация → 20-30 релевантных
5. Price/MOQ/Lead-time benchmark

**Что включено в результат:**

| Поле | Описание |
|------|----------|
| Компания | Название (EN) + ссылка |
| Платформа | Alibaba / Made-in-China |
| Цена | min–max FOB |
| MOQ | диапазон/минимум |
| Локация | провинция/город |
| Стаж | годы на платформе |
| Метрики | рейтинг/response rate |
| Badges | Trade Assurance / Audited |
| Индикатор | 🟢🟡🔴 + объяснение |

**Price/MOQ Benchmark (верхний блок):**
- Price corridor: min / median / max
- MOQ corridor: типовые MOQ по рынку
- Lead-time (индикативно)

**Дополнительно:**
- Кнопка "Сформировать запрос" — AI генерирует RFQ для копирования
- Кнопка "Проверить" → апсейл на Продукт 1/2

**Формат:** Интерактивный веб-отчёт + экспорт в Excel/PDF

**Источник:** Apify scrapers (Alibaba, Made-in-China)

### 3.5. Продукт 4: Анализ рынка поставок (KZ) ($50)

**Суть:** Отчёт о реальных поставках товара из Китая в Казахстан за 12 месяцев.

**Входные данные:**
- Категория/описание товара (через AI-диалог)
- HS-код (4-8 цифр)

**Что включено (данные):**

| Раздел | Данные |
|--------|--------|
| Обзор рынка | Общий объём импорта в КЗ по HS |
| Топ экспортёров | Список китайских компаний |
| Объёмы | Вес/стоимость/количество |
| Ценовой диапазон | min–max–avg |
| Динамика | По месяцам |
| Сезонность | Пики |

**Actionable Insights:**
- Концентрация рынка (доминирование vs фрагментация)
- Стабильность потока
- Ценовой ориентир
- Рекомендованный следующий шаг

**Конфиденциальность:** Импортёры (KZ компании) НЕ раскрываются

**Формат:** PDF + веб-отчёт

**Источник:** Tendata API

## 4. Бесплатные инструменты (лид-магниты)

Доступны после регистрации.

### 4.1. Калькулятор Landed Cost

**Суть:** Расчёт полной стоимости импорта (пошлины, НДС, доставка)

**Входные данные:**
- HS-код или описание товара
- FOB цена
- Объём/вес
- Точка назначения (Алматы, Ташкент и т.д.)

**Выходные данные:**
- Пошлина + НДС
- Примерная стоимость доставки
- Итоговый landed cost
- Разбивка по компонентам

**Источник:** Копия бота Xport с настройками

### 4.2. HS-код определитель

**Суть:** AI-классификация товара → HS-код

**Процесс:**
- Пользователь описывает товар
- AI определяет HS-код + альтернативы + уверенность
- Пользователь подтверждает

### 4.3. Бот оценки рисков сделки

**Суть:** Интерактивный опросник (5-7 вопросов) → карта рисков

**Вопросы:**
- Новый поставщик или уже работали?
- Какие условия оплаты?
- Есть ли контракт?
- Как планируете проверять качество?

**Выход:** Карта рисков с рекомендациями по митигации

## 5. Контентные разделы (бесплатно после регистрации)

### 5.1. Карта производителей

**Суть:** Интерактивная карта Китая с указанием специализации регионов/провинций/городов.

**Примеры:**
- Фошань → керамика, плитка
- Иу → мелкий опт, товары народного потребления
- Шэньчжэнь → электроника
- Дунгуань → мебель, фурнитура

**Формат:** Интерактивная карта с фильтрами по категориям

**Наполнение:** Ручной сбор из открытых источников

### 5.2. Библиотека

**Суть:** Полезные материалы по работе с Китаем

**Контент:**
- Гайды по проверке поставщиков
- Шаблоны документов (контракты, NDA, спецификации)
- Чек-листы (вопросы поставщику, приёмка груза)
- FAQ по таможне ЕАЭС
- Глоссарий терминов

**Источник:** Агрегация из открытых источников + собственные материалы

### 5.3. Торговые зоны и хабы

**Суть:** Справочник китайских торговых зон, экспортных хабов, которые могут помочь иностранным партнёрам.

**Типы:**
- Free Trade Zones (自由贸易区) — Shanghai FTZ, Shenzhen и др.
- Cross-Border E-commerce Zones (跨境电商综合试验区)
- Export Processing Zones
- Бондовые склады

**Информация по каждой зоне:**
- Название, локация
- Специализация
- Контакты
- Чем может помочь импортёру

### 5.4. Выставки

**Суть:** Календарь выставок в КНР по категориям

**Информация:**
- Canton Fair и другие крупные выставки
- Отраслевые выставки (стройматериалы, электроника, текстиль)
- Даты, локация, ссылки

**Обновление:** Ручной апдейт раз в квартал

### 6.2. AI-чат: архитектура

**Принцип:** На каждой странице свой бот с контекстными настройками.

| Раздел | Фокус бота |
|--------|------------|
| Продукт 1 | Помощь с проверкой компании, объяснение справки |
| Продукт 2 | Анализ экспортного профиля, интерпретация |
| Продукт 3 | Помощь с поиском, уточнение параметров |
| Продукт 4 | Анализ рынка, выводы |
| Карта | Информация о регионах, рекомендации |
| Библиотека | Навигация по материалам |
| Калькулятор | Помощь с расчётами |

**Важно:**
- Разные system prompts для каждого раздела
- Общий архив переписок по user_id
- Бот может направить в другой раздел: "Для этого перейди в раздел X"
- Услуги можно "врезать" прямо в диалог (оплата → генерация)

**Хранение:**

```
Таблица: chat_history
- id
- user_id
- section (какой раздел)
- messages (JSON array)
- created_at
- updated_at
```

Пользователь может читать старые диалоги, но каждый раз начинает новый.

## 7. Data Layer и Supplier ID

### 7.1. Единый Supplier ID

Для связки данных между продуктами вводится логика идентификации:

- **QCC:** USCC → canonical ID
- **Tendata:** Поиск по USCC → привязка
- **Apify:** Ссылки на профили → вероятностный матч

**Результат:** Пользователь видит одного поставщика во всех продуктах.

### 7.2. Кеширование

**Что сохраняем:**
- Агрегаты и признаки (features)
- Факт экспорта, страны, HS-направления
- Тип компании, статус, возраст
- Платформенные метрики

**Что НЕ сохраняем:**
- Сырые trade-записи (юридические риски)
- Данные, которые могут восприниматься как перепродажа

**Цель:**
- Ускорение отчётов
- Снижение себестоимости
- Основа для будущего мониторинга

## 11. Риски и митигация

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| QCC API недоступен или дорого | Средняя | Переговоры заранее, fallback на ручной сбор |
| Tendata дорожает/лимиты | Средняя | Оптимизация запросов, кеш, top-k проверки |
| Apify scrapers ломаются | Высокая | Мониторинг, 2 платформы как резерв |
| Ошибка идентификации компании | Средняя | USCC как вход, подтверждение пользователя |
| Низкая конверсия FREE→PAID | Средняя | A/B тесты, итерации на данных |
| Клиенты ожидают гарантий | Высокая | Чёткие дисклеймеры везде |

## 12. Дисклеймеры

### Продукт 1
> Отчёт составлен на основе данных из открытых государственных источников КНР. TradeLab не несёт ответственности за полноту и актуальность данных в первоисточнике. Отчёт носит информационный характер и не является юридическим заключением.

### Продукт 2
> Данные об экспортной активности получены из международных таможенных баз данных и могут иметь задержку 1–3 месяца. Объёмы являются оценочными. Блок "Релевантность к сделке" — аналитическая интерпретация признаков, а не гарантия результатов сотрудничества.

### Продукт 3
> Результаты поиска и риск-индикаторы основаны на публичных данных торговых платформ и предназначены для предварительного отбора кандидатов. Для принятия решения рекомендуется использовать проверку по продуктам 1–2.

### Продукт 4
> Отчёт содержит агрегированные данные о поставках из Китая в Казахстан; информация об импортёрах не раскрывается. Данные могут быть неполными для отдельных категорий.

## 14. Ключевые принципы

### 14.1. От «отчётов» к «решениям»
Каждый продукт отвечает на управленческий вопрос, а не просто выдаёт данные.

### 14.2. Evidence-first + Human-in-the-loop
- Данные показываются явно
- Выводы сопровождаются пояснением
- При низкой уверенности — запрос подтверждения

### 14.3. AI как интерфейс, не как оракул
LLM используется для удобства взаимодействия, но не как "арбитр истины".

### 14.4. Прозрачность ограничений
Честные дисклеймеры. Не обещаем гарантий. Позиционируем как инструмент для принятия решений.
