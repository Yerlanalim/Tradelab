## План P3 — многошаговый поиск и стабилизация экспорта

### 1) Как сейчас работает P3 (кратко)
- Режим `supplier_search` активируется на `/products/supplier-search`.
- Edge Function `chat_handler` делает web‑search и ждёт JSON.
- Preview/Full идут одним пайплайном, с дедупом и фильтрацией ссылок.
- Экспорт PDF/XLSX — через `/api/reports/export-pdf` и `/api/reports/export-xlsx`, с токеном.

### 2) Идеальный многошаговый поиск (агентный пайплайн)
**Шаг 1 — Нормализация запроса**
- Взять форму → привести к EN/中文 (обязательные требования).
- Сформировать 2–3 query: базовый, уточнённый, запасной.

**Шаг 2 — Сбор URL (web search)**
- Запросы вида `site:alibaba.com` / `site:made-in-china.com`.
- Исключить локализованные домены (`russian.alibaba.com`, `ru.made-in-china.com`).

**Шаг 3 — Preview**
- Валидация URL (HTTP 200 + тип страницы).
- Выдать 3–5 карточек, без enrich, только ключевые поля.

**Шаг 4 — Уточнение**
- Если мало/не то — уточнить параметры (материал, MOQ, бюджет).
- Второй цикл поиска (макс 1–2 итерации).

**Шаг 5 — Полный сбор**
- Из валидных URL извлечь: название, цена, MOQ, регион, ссылка.

**Шаг 6 — Enrichment топ‑30**
- Дособрать факторы доверия: тип компании, аудиты, стаж, бейджи.

**Шаг 7 — Сводка и отчёт**
- Скоринг + отбор 10 лучших.
- Формирование отчёта + экспорт PDF/XLSX.

### 3) Список изменений для реализации
#### Backend (Supabase + Edge)
- Разделить `chat_handler` на этапы (search → verify → extract → enrich → rank).
- Добавить отдельные tool‑шаги/endpoint для async режима (job queue).
- Жёсткая валидация доменов и исключение локализованных версий.
- Добавить перевод запроса на EN/中文 перед web‑search.
- Ввести метрики качества: % валидных ссылок, пустые поля, доля источников.

#### Frontend (Next.js)
- UI прогресс‑бар по этапам.
- Preview отдельным блоком, без “галлюцинаций”.
- Обработка уточнений (1–2 шага).
- Явный статус асинхронного поиска.

#### Экспорт PDF/XLSX (стабилизация)
- Перейти на cookie‑auth (server‑side) вместо передачи токена.
- Добавить retry/refresh перед экспортом.
- Ввести async job для генерации PDF/XLSX (чтобы избежать 401/timeout).
- Логировать ошибки экспорта и показывать пользователю корректные сообщения.
