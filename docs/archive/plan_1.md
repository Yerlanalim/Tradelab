## План улучшений P3 (Supplier Search)

### Цели
- Повысить качество результатов поиска и доверие к источникам.
- Устранить 401 в экспорте PDF/XLSX.
- Укрепить безопасность и производительность Supabase.
- Обеспечить прозрачные метрики и ретеншн данных.

### Оптимальные методы решения
- **Многошаговый пайплайн**: поиск URL → валидация → извлечение полей.
- **Модель высокого качества для web‑search**: GPT‑5 только на этапах поиска/извлечения.
- **Доказательная база**: реальные карточки, проверка ссылок, контроль источников.
- **Fail‑safe UX**: понятные ошибки сессии и повторные попытки.
- **DB‑hardening**: RLS политики, индексы на FK, search_path.
