## 0. Принципы v2.2

### 0.1. От «отчётов» к «решениям»
Каждый продукт отвечает на управленческий вопрос импортёра:
- **Можно ли доверять контрагенту юридически?** → Справка + Risk Assessment
- **Есть ли релевантный экспорт под мою сделку?** → Экспортный профиль
- **Кого из поставщиков стоит проверять?** → Поиск + светофор
- **Кто реально возит этот товар в КЗ?** → Анализ рынка

### 0.2. Evidence-first + Human-in-the-loop
- Данные показываются явно с указанием источника
- AI-выводы сопровождаются объяснением факторов
- При низкой уверенности — запрос подтверждения пользователя

### 0.3. Гибридный подход к данным
Комбинируем официальные API + AI web search для оптимального баланса стоимости и качества.

### 0.4. Единый бот (Unified Bot) вместо набора “ботов по страницам”
На платформе **один** бот (UI в сайдбаре), который работает в разных **режимах** в зависимости от страницы:
- **Assistant** (по умолчанию): ответы/подсказки/HS‑код/следующий шаг; при запросе поиска поставщиков — **направляет** в `/products/supplier-search`, но не выполняет полный поиск.
- **Supplier Search** (только `/products/supplier-search`): guided flow поиска, preview бесплатно, полный отчёт — платно.
- **Report** (страницы P1/P2/P4 и отчёты): интерпретация отчётов и апсейл.

> Детальная логика режимов, ограничений и UX описана в `docs/TradeLab_Unified_Bot_Concept_v1.md`.

## 3. Продукт 2: Экспортный профиль + Релевантность к сделке

## 4. Продукт 3: Поиск поставщиков (Supplier Search Bot)

### 4.1. Суть продукта
Диалоговый AI-бот для поиска и предварительного скорринга китайских поставщиков. Заменяет устаревший подход с legacy scrapers на нативный LLM с web search.

> **"Скажи боту, что ищешь — получи топ-10 проверенных поставщиков за 3 минуты"**

### 4.2. Почему LLM web search вместо legacy scrapers

| Критерий | Legacy scrapers (было) | LLM Web Search (стало) |
|----------|--------------|------------------------|
| Себестоимость | $4–5 | $0.50–1.50 |
| Надёжность | Scrapers часто ломаются | Адаптивный поиск |
| Качество | Жёсткая структура | Понимает контекст |
| Поддержка | Требует мониторинга | Минимальная |
| Масштабируемость | Лимиты Alibaba | Гибкие запросы |

### 4.3. User Flow

**Шаг 1: Первичный запрос (бесплатно)**
```
Бот: Привет! Опиши, что ищешь — я найду поставщиков.
```

## 5. Продукт 4: Анализ рынка поставок (KZ)

### 5.1. Суть продукта
Отчёт о реальных поставках товара (по HS-коду) из Китая в Казахстан за последние 12 месяцев.

### 5.2. Ключевая ценность
Пользователь видит **реальных экспортёров** и может:
- Собрать shortlist "тех, кто уже возит в КЗ"
- Оценить рыночные диапазоны
- Понять структуру конкуренции и сезонность

### 5.3. Входные данные
- Категория / описание товара (через AI-диалог)
- HS-код (4–8 цифр)
- Период (по умолчанию 12 месяцев)

### 5.4. Что включено в отчёт

| Раздел | Данные |
|--------|--------|
| Обзор рынка | Общий объём импорта в КЗ по HS |
| Топ экспортёров | Список китайских компаний |
| Объёмы | Вес/стоимость/количество |
| Ценовой диапазон | min–max–avg |
| Динамика | По месяцам |
| Сезонность | Пики |

### 5.5. Actionable Insights
- **Концентрация рынка:** 2–3 игрока доминируют или рынок фрагментирован
- **Стабильность потока:** ровный импорт или сезонные пики
- **Ценовой ориентир:** где находится медиана, подозрительные выбросы
- **Рекомендованный следующий шаг:** "выберите 3–5 экспортёров → проверьте по бандлу 1+2"

### 5.6. Конфиденциальность
Импортёры (казахстанские компании) **НЕ раскрываются**.

### 5.7. Unit Economics
- Цена: **$50 (5,000 TC)**
- Себестоимость (Tendata): **$10–15**
- Маржа: **70–80%**

### 5.8. Источник данных
**Tendata API**: `catalog=imports`, `destinationCountryCode=KAZ`
