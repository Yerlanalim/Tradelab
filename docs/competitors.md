# Конкурентный анализ для TradeLab v2.1
## AI-платформы для B2B международной торговли и сорсинга из Китая

**Дата:** январь 2026  
**Фокус:** Новые продукты (2023-2025) с AI-функционалом для SMB в международной торговле

---

## Резюме

После изучения концепции TradeLab v2.1 и исследования рынка выделены **12 релевантных конкурентов и схожих продуктов**, которые работают в сфере B2B sourcing с AI-функционалом. Анализ разделён на категории:

1. **AI Sourcing Platforms** — полноценные платформы с AI для поиска поставщиков
2. **Trade Data & Intelligence** — платформы торговых данных и аналитики
3. **AI Tools от крупных игроков** — новые AI-продукты Alibaba и Made-in-China

### 1.1 Cavela
| Параметр | Информация |
|----------|------------|
| **Основание** | 2023 (США) |
| **Финансирование** | $8.6M (Seed $2M в сентябре 2024, $6.6M в ноябре 2025) |
| **Инвесторы** | XYZ Venture Capital, Susa Ventures, Propel Ventures |
| **Основатель** | Anthony Sardain (ex-data science lead, семейный опыт в торговле) |
| **Целевой рынок** | США, Европа — SMB бренды в fashion/apparel |

**Основные продукты:**
- AI-агенты для автоматизации sourcing: поиск, переговоры, сравнение цен
- Сеть 200,000+ поставщиков в 40+ странах (акцент на Китай, Мексика, Вьетнам)
- Автоматическая коммуникация с фабриками через WhatsApp/email/text

**Ключевые фичи:**
- AI автоматически контактирует десятки поставщиков одновременно
- Собирает котировки и ведёт переговоры без участия человека
- Снижение стоимости закупок до 37% по сравнению с self-sourcing
- Централизованный дашборд для всех переговоров

**Позиционирование:** "Виртуальный sourcing agent" — автоматизация всего процесса от поиска до контракта

**Релевантность для TradeLab:** ⭐⭐⭐⭐⭐
- Прямой конкурент по подходу (AI + sourcing)
- Фокус на SMB — та же аудитория
- НО: нет фокуса на СНГ/ЕАЭС, нет Deal Tracker, нет расчёта пошлин

## 2. Trade Data & Intelligence Platforms

### 2.1 ImportYeti
| Параметр | Информация |
|----------|------------|
| **Основание** | 2021 (США) |
| **Модель** | Freemium |
| **Данные** | 70M+ US customs records |
| **Целевой рынок** | США — e-commerce sellers, Amazon sellers |

**Основные продукты:**
- Бесплатная база таможенных данных США (Bill of Lading)
- Поиск поставщиков конкурентов
- Анализ объёмов поставок
- HS Code Explorer

**Ключевые фичи:**
- Данные с 2015 года
- Поиск по компании, продукту, supplier
- Анализ supplier relationships
- Premium: advanced search, CSV exports

**Ограничения:**
- Только морские перевозки в США
- Нет данных по воздушным/наземным перевозкам
- Нет данных по другим странам

**Ценообразование:** Free tier + Premium

**Релевантность для TradeLab:** ⭐⭐⭐⭐
- Модель "freemium data platform" — можно заимствовать
- Показывает ценность публичных таможенных данных
- Ограничение: США-центричный

## 6. Ключевые выводы для TradeLab

### Возможности (Blue Ocean)

1. **Географическая ниша**: Ни один конкурент не фокусируется на ЕАЭС/СНГ
2. **Двусторонняя модель**: Только Made-in-China делает это, но не для СНГ
3. **Deal Tracker**: Уникальная фича — CRM для сделок с risk alerts
4. **Локальный customs calculator**: Интеграция с Xport.kz — unique selling point
5. **Русский + Китайский**: Языковое преимущество перед глобальными платформами

### Угрозы

1. **Accio/Alibaba**: Бесплатный AI sourcing может создать expectations
2. **Cavela/Sourcy**: Если выйдут на СНГ — прямые конкуренты
3. **Made-in-China SourcingAI**: Похожая двусторонняя модель

### Рекомендации

1. **Дифференциация**: Усилить фокус на "импорт в ЕАЭС" как уникальную компетенцию
2. **Партнёрства**: Tendata для данных, Xport для customs — критично
3. **AI Agent**: Следить за Cavela/Accio — тренд на автоматические переговоры
4. **Learning Hub**: Аналоги есть (Sourcify), но на русском — уникально
5. **WeChat Mini Program**: Правильный подход для китайских экспортёров
