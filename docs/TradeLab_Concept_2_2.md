## 1. Суть проекта

**TradeLab** — self-service платформа инструментов для импортёров из Казахстана и ЕАЭС, которые работают с китайскими поставщиками.

### 1.1. Ключевое ценностное предложение

> **Мы продаём время, уверенность и структурированные решения.**
> 
> - Юридическая справка о компании — за минуты вместо дней
> - Экспортный профиль с оценкой релевантности — вместо гадания
> - Подбор поставщиков с ценовым бенчмарком — вместо 50 открытых вкладок
> - Анализ реальных поставок в Казахстан — вместо слепого поиска

### 1.2. Чем TradeLab НЕ является

- ❌ Не маркетплейс — нет участия в сделках
- ❌ Не sourcing-агент — не ведём переговоры за клиента
- ❌ Не гарант — нет escrow, нет комиссий с товара
- ❌ Не логист — только ориентиры по стоимости

### 1.3. Бизнес-модель

**Система Trade Credits:**
- Внутренняя валюта платформы (100 TC = $1 = 500 ₸)
- Пакеты с бонусами до 50%
- Реферальная программа
- Снижение барьера для микроплатежей

### 3.2. Продукт 1: Справка о компании + Risk Assessment ($20 / 2,000 TC)

**Суть:** Юридическая справка о китайской компании с AI-интерпретацией рисков.

**Входные данные:**
- **Unified Social Credit Code (USCC)** — 18 символов
- Пользователь получает USCC от поставщика (инструкция на сайте)

**Архитектура данных (гибридная):**

| Слой | Источник | Данные |
|------|----------|--------|
| 1. Официальные данные | QCC Lite API ($3) | Регистрация, статус, адрес, законный представитель, дата, срок действия, уставный капитал |
| 2. AI-обогащение | LLM web search | Business scope (перевод), история изменений, упоминания в судебных делах, чёрные списки, отзывы |
| 3. Risk Assessment | AI-интерпретация | Светофор + рекомендации по митигации рисков |

**Что включено в отчёт:**

| Раздел | Данные | Источник |
|--------|--------|----------|
| Регистрация | Название (中文/EN), дата, статус (Active/Inactive) | QCC Lite |
| Основные реквизиты | USCC, законный представитель, уставный капитал | QCC Lite |
| Адрес | Юридический адрес | QCC Lite |
| Срок действия | Период операций (если срочный) | QCC Lite |
| Business scope | На китайском + AI-перевод | QCC Lite + AI |
| Контакты | Телефон/email (если найдены) | AI web search |
| Юридическая история | Судебные дела, чёрные списки, нарушения | AI web search |
| Дополнительная информация | Новости, отзывы, упоминания | AI web search |

### 3.3. Продукт 2: Экспортный профиль + Релевантность к сделке ($20 / 2,000 TC)

**Суть:** Аналитический отчёт об экспортной активности компании за последние 12 месяцев.

**Входные данные:**
- USCC (предпочтительно)
- Или название компании (EN/中文)

**Что включено (данные):**

| Раздел | Данные |
|--------|--------|
| Факт экспорта | Подтверждение активности |
| Период | Первая/последняя отгрузка |
| Объёмы | Общий объём USD (оценка) |
| География | Топ-10 стран |
| Экспорт в СНГ/ЕАЭС | KZ/RU/UZ/KG — отдельным блоком |
| HS-коды | HS-направления экспорта |
| Динамика | График по месяцам, тренд |
| Частота | Среднее отгрузок/месяц |

**Блок "Релевантность к сделке":**
- **HS match** — совпадает ли экспорт с вашим товаром
- **Масштаб** — сопоставимы ли объёмы с вашей потребностью
- **Стабильность** — регулярность поставок
- **Региональная пригодность** — опыт поставок в СНГ

**Формат:** PDF, 3-4 страницы

**Источник:** Tendata API

**Unit Economics:**
- Цена: $20 (2,000 TC)
- Себестоимость: $3–5
- Маржа: **75–85%**

### 3.4. Продукт 3: Поиск поставщиков (Supplier Search Bot) — $5 / 500 TC

**Суть:** Диалоговый AI-бот для поиска и предварительного скорринга китайских поставщиков.

> **"Скажи боту, что ищешь — получи топ-10 проверенных поставщиков за 3 минуты"**

**Ключевое изменение v2.2:** Замена legacy scrapers на нативный LLM с web search tool.

| Было (v2.1) | Стало (v2.2) |
|-------------|--------------|
| Legacy scrapers | LLM web search (GPT-4o) |
| $4–5 себестоимость | $0.50–1.50 себестоимость |
| Ненадёжно, ломается | Адаптивно, понимает контекст |
| $10 цена | $5 цена (500 TC) |

**User Flow:**

1. **Preview (бесплатно):** Бот показывает 5 примеров результатов
2. **Подтверждение:** Пользователь подтверждает, что ищет правильно
3. **Оплата:** Списание 500 TC
4. **Полный анализ:** 10 поставщиков со скоррингом

**Что включено в результат:**

| Поле | Описание |
|------|----------|
| Компания | Название (EN) + ссылка |
| Платформа | Alibaba / Made-in-China |
| Цена | min–max FOB |
| MOQ | диапазон/минимум |
| Локация | провинция/город |
| Стаж | годы на платформе |
| Статусы | Trade Assurance / Gold Supplier / Audited |
| Светофор | 🟢🟡🔴 + объяснение риска |

**Светофорная система:**
- 🟢 **Низкий риск:** Производитель, 5+ лет, Audited, Trade Assurance, цена в рынке
- 🟡 **Средний риск:** Требует уточнения (торговая компания с хорошей репутацией, нет данных об экспорте в СНГ)
- 🔴 **Высокий риск:** Цена ниже рынка >30%, новый аккаунт, нет верификации

**Дополнительные действия (после отчёта):**
- `[📝 Сформировать RFQ для топ-3]` — 100 TC
- `[🔍 Проверить компанию]` → Продукт 1 (2,000 TC)
- `[📊 Экспортный профиль]` → Продукт 2 (2,000 TC)
- `[🔢 Определить HS-код]` — бесплатно
- `[💰 Рассчитать landed cost]` — бесплатно

**Формат:** Интерактивный отчёт в чате + экспорт PDF/Excel

**Unit Economics:**
- Цена: $5 (500 TC)
- Себестоимость: $0.50–1.50 (LLM + web search)
- Маржа: **70–90%**

### 6.3. Единый AI‑бот (Unified Bot): архитектура

**Принцип v2.2:** на платформе **один** AI‑бот (в сайдбаре), который работает в разных **режимах** в зависимости от текущей страницы (page_context).

#### Режимы (mode)
- **Assistant** — режим “помощника” по умолчанию на большинстве страниц:
  - отвечает, объясняет, помогает с HS‑кодом/терминами/следующим шагом;
  - **не выполняет полный поиск поставщиков**;
  - при запросе “найти поставщиков” даёт чип/ссылку и направляет на `/products/supplier-search`.
- **Supplier Search** — активен **только** на странице `/products/supplier-search`:
  - guided flow: уточнения → **preview бесплатно** → подтверждение → **списание 500 TC** → полный отчёт.
- **Report** — активен на страницах отчётов/продуктов (P1/P2/P4):
  - помогает интерпретировать отчёт;
  - предлагает апсейл/кросс‑селл (P1↔P2↔P4↔P3).

#### Backend‑контракт (единая точка входа)
Рекомендуемая реализация — единая Edge Function (условно `chat_handler`), которая:
- принимает `message`, `messages`, `page_context` и `session_id`;
- определяет `mode` по `page_context`;
- формирует system prompt по `mode` и контексту;
- возвращает не только текст, но и управляющие поля для фронта: `tool_calls`, `suggested_chips`, `ui_hints`.

> Детализация UX/режимов/ограничений инструментов описана в `docs/TradeLab_Unified_Bot_Concept_v1.md`.

## 10. Дисклеймеры

### Продукт 1
> Отчёт составлен на основе официальных данных госреестра КНР (QCC) и дополнен информацией из открытых источников. TradeLab не несёт ответственности за полноту и актуальность данных. Блок "Risk Assessment" — аналитическая интерпретация признаков, не является юридическим заключением.

### Продукт 2
> Данные об экспортной активности получены из международных таможенных баз данных и могут иметь задержку 1–3 месяца. Объёмы являются оценочными. Блок "Релевантность к сделке" — аналитическая интерпретация, не гарантия результатов.

### Продукт 3
> Результаты поиска основаны на публичных данных торговых платформ. Светофорная оценка предназначена для предварительного отбора. Для принятия решения рекомендуется проверка по продуктам 1–2.

### Продукт 4
> Отчёт содержит агрегированные данные о поставках из Китая в Казахстан; информация об импортёрах не раскрывается.
