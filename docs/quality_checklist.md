# Quality Checklist

## Перед релизом
- Линтер и типы проходят без ошибок
- RLS политики включены и проверены
- Все ключи в `.env` заполнены
- Ошибки логируются в Sentry (если DSN задан)
- Контентные разделы читаются из Supabase

## Smoke checks
- Логин/регистрация работают
- Reports list загружается для авторизованного пользователя
- Создание demo‑отчетов работает
- Контентные страницы отображаются
