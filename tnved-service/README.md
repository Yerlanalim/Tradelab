Инструкция для запуска проекта TradeLab
Этот проект использует архитектуру монорепозитория. Все основные действия выполняются из корневой папки.

1. Установка окружения
Убедитесь, что у вас установлен Node.js 18+.

# Установка всех зависимостей (фронтенд + все микросервисы)
npm install
2. Подготовка базы данных ТНВЭД
База данных ТНВЭД (.db) не хранится в репозитории, так как является бинарным файлом и часто обновляется. Она автоматически собирается из актуального Excel-файла.

# Сборка SQLite базы из XLSX
npm run build:tnved:db
Скрипт сам найдет файл TWS_TNVED_*.xlsx в папке tnved-service/data/ и преобразует его в оптимизированную SQLite базу.

3. Запуск проекта
Для удобства разработки настроен одновременный запуск всех сервисов (Next.js, Backend, TNVED Microservice) одной командой:

# Запуск всех сервисов в режиме разработки
npm run dev
Доступные адреса:
Frontend: http://localhost:3000
Backend API: http://localhost:3001
TNVED Service: http://localhost:3002
Примечание: Если нужно обновить справочник кодов, просто положите новый XLSX файл в tnved-service/data/ и снова запустите npm run build:tnved:db.



# ТНВЭД/HS Code Reference Microservice

Offline-first микросервис для поиска кодов ТНВЭД (Товарная номенклатура внешнеэкономической деятельности) / HS (Harmonized System).

## Особенности

- ✅ **Offline-first**: работает без интернет-соединения
- 🤖 **AI Fallback & Virtual Records**: если в базе нет кода, система спросит ИИ и создаст виртуальную карточку
- ⚡ **FTS5 + Лемматизация**: полнотекстовый поиск с поддержкой окончаний (автомобиль/автомобили)
- 🚀 **Performance**: SQLite оптимизирован через Memory Mapping (mmap) и агрессивное кэширование
- 🛠 **Monorepo Ready**: полная интеграция с NPM Workspaces в TradeLab

## Профессиональная конфигурация (.env)

Сервис берет настройки из корня проекта или локального `.env`.

| Переменная | Описание | Значение по умолчанию |
|------------|----------|-----------------------|
| `TNVED_PORT` | Порт микросервиса | `3002` |
| `P3_BASE_MODEL` | Модель для AI Fallback | `gpt-4o-mini` |
| `ENABLE_AI_FALLBACK` | Глобальный переключатель ИИ | `true` |
| `AI_FALLBACK_MIN_RESULTS` | Лимит поиска для активации ИИ | `3` |
| `AI_FALLBACK_MAX_BEST_SCORE`| Порог «плохого» результата | `-5` |
| `DB_PATH` | Относительный путь к БД | `./data/tnved.db` |
| `SQLITE_MMAP_SIZE` | Размер Memory Mapping | `2147483648` (2GB) |

## Архитектура поиска

1.  **FTS5 Search**: Основной метод. Использует алгоритм `AND` для нахождения всех ключевых слов.
2.  **Pseudo-Lemmatization**: Автоматически обрезает окончания (а, е, и, о, у, й...) и использует префиксы для поиска корней.
3.  **AI Fallback**: Срабатывает, если:
    - Найдено меньше `MIN_RESULTS`
    - Релевантность лучшего совпадения хуже `MAX_BEST_SCORE`
4.  **Virtual Record**: Если AI нашел код, которого нет в вашем XLSX, он будет выведен с пометкой `[AI Suggestion]`.

## Управление (из корня проекта)

- **База данных**: `npm run build:tnved:db`
- **Сборка TS**: `npm run build:tnved`
- **Запуск**: `npm run dev`
